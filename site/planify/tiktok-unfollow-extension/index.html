About the extension

A Chrome extension that actually works

The TikTok Unfollow Agent is a Manifest V3 Chrome extension. It runs entirely in your browser — no external servers, no API calls, no data collection. It simply automates the clicks you'd do manually.

Manifest V3 compatible

Built for the latest Chrome extension platform. No deprecated APIs, no background pages, no issues with Chrome's new architecture.

🔒

No password, no data

The extension never sees your TikTok password. It works in your already-logged-in tab. Zero telemetry, zero network calls.
